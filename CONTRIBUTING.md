# Contribuir

1. Describe pasos, resultado esperado, versión de Windows y versión de GamesDock. Para fallos visuales, indica tema, posición, tamaño y estado de animación/agrandado.
2. Compila con app/build.ps1 y limita cada cambio a su objetivo.
3. Ejecuta las pruebas relevantes. Para geometría, animación o estilos, ejecuta la suite completa de [Arquitectura](docs/development/ARQUITECTURA.md) y revisa capturas en ambos idiomas.
4. Actualiza CHANGELOG.md y la documentación afectada. Adjunta resultados y límites de validación.

No publiques config.json, claves de SteamGridDB, rutas personales ni cachés. Los resultados generados van en artifacts/. Conserva la licencia MIT.
